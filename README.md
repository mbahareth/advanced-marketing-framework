# Advanced Marketing Framework

An income-segmented persuasion skill for high-impact marketing and copywriting.

This skill adapts core messaging to the psychological drivers of different income levels and enforces a five-pillar content methodology. It is designed for agents that create marketing copy, analyze websites, develop brand messaging, or produce promotional content.

**Repository:** [mbahareth/advanced-marketing-framework](https://github.com/mbahareth/advanced-marketing-framework)

## Core Framework: Income-Segmented Persuasion

Different economic segments respond to fundamentally different triggers:

| Segment | Core Focus | Key Triggers | Psychological Driver |
|---------|------------|--------------|----------------------|
| **Low-Income** | **Promises** | Guarantees, Testimonials, Tactics, Goals | Security, risk reduction, immediate practical solutions |
| **Middle-Income** | **Assets** | ROI, Efficiency, Status, Long-term Value | Aspiration, smart investment, upward mobility |
| **High-Income** | **Philosophy** | Insight, Ideas, Leadership, Identity | Self-actualization, legacy, worldview reinforcement |

## Five-Pillar Content Methodology

Every piece of content must apply all five pillars:

1. **Steve Jobs Style** — Extreme clarity, grand vision, enemy-vs-hero narrative
2. **NLP Techniques** — Sensory language, presuppositions, audience mirroring
3. **Modern Marketing Frameworks** — Jobs-to-be-Done + StoryBrand (customer as hero, brand as guide)
4. **The Nudge** — Choice architecture, social proof, reduced friction
5. **Cliffhangers** — Open loops that drive continued engagement

## Dual-Language Requirement

All final outputs must be produced in both **English** and **Arabic** (Modern Standard Arabic / Fus'ha).

The Arabic version must carry the same emotional intensity, psychological weight, and persuasive power as the English version — not a literal translation.

## When to Use

- Creating or rewriting marketing copy, landing pages, emails, ads, or website content
- Analyzing an existing website or campaign for persuasive effectiveness
- Developing brand messaging or positioning for a specific audience segment
- Generating promotional materials that must work in both English and Arabic

## Quick Start for Agents

1. Identify the target income segment (Low / Middle / High).
2. Select the matching angle: Promises, Assets, or Philosophy.
3. Apply all five pillars while drafting.
4. Deliver the final result in both English and Arabic with equivalent emotional weight.
5. Include at least one open loop and confirm segment alignment.
